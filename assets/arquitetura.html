Como funciona o RAG nesse projeto

Um chat que responde só com base nos documentos que eu dou para ele. Antes de chamar a IA, ele procura os trechos certos e manda junto. Se não acha nada, diz que não sabe em vez de inventar.

As peças tudo roda no meu computador, de graça

Chat no navegador
Vue.js
API em C#
ASP.NET Core · organiza tudo
Ollama
a IA: cria vetores e escreve a resposta
Qdrant
banco vetorial: guarda e busca trechos

1. Guardando os documentos feito uma vez

Documento
manual, FAQ, política…
Pedaços
quebra em trechos de ~800 letras
Vetores
cada trecho vira números que guardam o sentido
Qdrant
fica tudo guardado

2. Respondendo uma pergunta a cada mensagem

Pergunta
"e com defeito?"
Entende o contexto
usa a conversa: "prazo de troca com defeito?"
Busca
acha os 4 trechos com sentido mais parecido
não achou nada? responde "não encontrei" ✋
Monta o pedido
pergunta + trechos + "use só isso"
IA responde
com base só nos trechos
Resposta + fontes
"até 90 dias [1]" e de qual arquivo veio
