Como o orquestrador funciona

pergunta do clienteMeu pedido 10240 está demorando. A air fryer tem em alguma loja para eu buscar hoje?
1
Orquestrador planeja
lê a descrição de cada skill e divide a pergunta em tarefas
{ "tarefas": [
  { "agente": "sac",     "tarefa": "Status do pedido 10240" },
  { "agente": "estoque", "tarefa": "Air fryer Crisp disponível em alguma loja?" } ] }
2
Agente SAC
skills/sac.md
→ consultar_pedido("10240")
Aguardando estoque · entrega prevista para 05/12
2
Agente Estoque
skills/estoque.md
→ consultar_estoque("air fryer")
0 unidades nas 3 lojas · reposição prevista para 02/12
3
Síntese
junta as respostas, sem acrescentar nenhum fato
"Seu pedido está aguardando estoque, com entrega prevista para 05/12. Por enquanto a air fryer não está disponível em nenhuma loja; a reposição está prevista para 02/12."
